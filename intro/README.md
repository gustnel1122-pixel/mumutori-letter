# 무무토리 첫 방문 인트로

자사몰 메인(`/`)에 처음 들어온 손님에게 한 번만 보이는 스크롤 인트로예요.
도토리가 굴러 들어옴 → 뚜껑이 열리며 씨앗 친구들 → 버터 차양 아래 작은 상점 → 편지 도착 → '둘러보기'.

- `mmi.js` — 인트로 전체(그림을 층층이 겹쳐 스크롤에 따라 움직임). 로고는 자사몰 머리글 로고를 같은 자리·같은 크기로 그대로 씀.
- `img/` — 낱개 그림(webp).
- 자사몰 쪽은 테마 설정 > 커스텀 코드 > `<head>`의 짧은 조각이 첫 방문인지 확인한 뒤 `mmi.js`를 불러요.
  - 다시 보기: 메인 주소 뒤에 `?intro=1`
  - 끄고 보기: `?intro=0`
  - 완전히 끄기: 커스텀 코드에서 '무무토리 첫 방문 인트로' 묶음을 지우고 저장
- 건너뛰기 버튼은 늘 보이고, Esc로도 닫혀요. 움직임 줄이기 설정이면 장면이 한 장씩 넘어가요.
